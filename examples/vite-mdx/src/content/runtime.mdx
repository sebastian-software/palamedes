# One locale per document

All {pageCount} pages share the locale selected when this document starts. The switcher loads a new document so framework state and non-React caches cannot retain the previous language.

<FeatureCard title="Thin Vite integration">
  The plugin selects `.mdx`, asks the native compiler for JSX, and lets the framework own rich
  rendering while translations use the same hook-free runtime getter as regular modules.
</FeatureCard>

This final page proves that linked MDX modules can share one catalog while remaining normal application modules.
