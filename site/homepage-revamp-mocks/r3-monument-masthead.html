03 · Fast — Performance

Every extract finishes faster than a blink.

A full extract and catalog update over 1,500 files takes 83.89 ms — 29× to 79× faster than every tool we measured doing the same job. (The one tool that skips catalog updates entirely is still 5.7× slower.) And that is the slow lane: touch five files and re-run, and it drops to 33 ms, because unchanged files are neither read nor parsed. The compared tools re-extract everything, every time.
