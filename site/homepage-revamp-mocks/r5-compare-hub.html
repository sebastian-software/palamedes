02 — When Palamedes is wrong for you

Four honest exits.

Vue / React Native

You need them today. Palamedes has neither and will not fake it — Lingui covers both first-party.

Hosted TMS

You want in-context editing against a hosted workflow now. That's Tolgee's home game.

No build step

You want runtime-only i18n without extraction or compilation. Key-based runtimes fit better.

Built-in MT

You want machine translation inside the tool. Palamedes keeps translation out of scope, deliberately.

Why native tooling, why now

The JS-toolchain generation is converging on the same answer from different directions — worker threads, experimental Rolldown hosts, native rewrites. Palamedes started on a Rust core instead of chasing one. This argument lives here, once — not repeated on every comparison page.
