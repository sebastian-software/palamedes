# Plans

`docs/plans` is reserved for active working plans only.

Rules:

- keep only documents that are still under active discussion or implementation
- move durable project decisions into [Decision Records](../../adr)
- once a plan is implemented or abandoned, delete it instead of keeping it as stale reference material

No active plans. Durable v2 decisions live in the [ADRs](../../adr) and the
[v2 migration guide](../migration-v2.md); implementation evidence lives in the
[catalog-delivery evidence report](../../benchmarks/catalog-delivery/README.md).
